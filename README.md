# teamrbr-media
## Team RBR Instagram media

Public storage for Team RBR's automated Instagram posts (Metricool collects media from the raw links).

- `brand/` – official KW Eden logo used in every self-built design
- `scripts/make_post.py` – backup builder: turns a slide spec into a branded Story (JPG) or Reel (MP4) when Canva is unavailable. Blocks the words "Realty" and "valuation" in copy.
- `media/YYYY-MM-DD/` – files uploaded by the daily task
